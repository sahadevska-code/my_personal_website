Follow a question from document preparation to retrieval and answer generation. Change the documents or question, run each stage, and see what the system is doing.

Key idea: documents are usually chunked and embedded before the user asks a question. At query time, the question is embedded, relevant chunks are retrieved, and those chunks are added to the prompt sent to the LLM.

Create chunks and embed a question, then retrieve.

This simulator ranks using cosine similarity over simplified word-feature vectors. Real systems may use neural embeddings, metadata filters, keyword search, reranking, or hybrid retrieval.
